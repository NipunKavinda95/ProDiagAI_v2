# Generic Rotating Equipment Maintenance Reference

## Scope

This simulated reference provides general maintenance information for
industrial motors, pumps, fans, compressors, conveyors and gearboxes.

It is intended for ProDiag AI V2 demonstration and RAG testing.

---

## Electric Motors

### Common Issues

- Bearing wear
- Overload
- Misalignment
- Cooling problems
- Electrical abnormalities

### Important Measurements

- Temperature
- Vibration
- Current
- RPM

### Maintenance Checks

- Bearings
- Coupling
- Shaft alignment
- Cooling system
- Electrical connections

## General Maintenance Principle

Machine condition should be evaluated using multiple sources of evidence:

- Live sensor data
- Historical trends
- ML prediction
- Anomaly detection
- Fault history
- Maintenance documentation

AI recommendations should be verified by qualified maintenance personnel.
